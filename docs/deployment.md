# Развёртывание

## Локальная production-проверка

```sh
npm ci
npm run check
npm run build
npm start
```

`npm start` запускает Wrangler с `dist/server/wrangler.json`; порт печатается
в терминале (обычно 8787). Откройте главную, нажмите расчётный обзор, затем:

```sh
npm run mcp:smoke -- http://127.0.0.1:8787/api/mcp
```

## Собственный Cloudflare Worker

Нужен свой Cloudflare-аккаунт. Публикация использует его лимиты и тариф.
Ключ LLM не требуется на сервере: MVP передаёт ключ пользователя на один запрос.

```sh
npm ci
npm run build
npx wrangler login
npx wrangler deploy --config dist/server/wrangler.json
```

Перед публикацией проверьте сгенерированный конфиг: `main: index.js`,
assets `../client`, `nodejs_compat`. Эти пути относительны `dist/server`.
Не развёртывайте только `dist/client`: MCP и агент требуют серверной части.
Имя Worker в конфиге формируется из package.json; задайте своё имя через Wrangler,
если оно занято. Вход Wrangler и тариф подтверждает владелец аккаунта.

## Sites

Авторский экземпляр связан с `.openai/hosting.json`. Source snapshot и build archive
передаются в Sites, после сохранения версии публикуется именно эта версия.
Копирование project_id не даёт прав на чужой Site. Для нового экземпляра нужна
собственная регистрация Site. Доступ по умолчанию ограничен владельцем; перед
защитой нужна публичная публикация или отдельно настроенный доступ преподавателя.

## Проверка после публикации

1. Главная загружается, пример содержит восемь запусков.
2. Без ключа расчётный обзор возвращает run-005 и сигнал для run-004.
3. `/api/health` возвращает status=ok.
4. Внешний SDK-клиент подключается к `/api/mcp` и выполняет compare_runs.
5. С собственным ключом задать свободный вопрос, проверить реальные MCP-вызовы.
6. Открыть ссылку без авторизации, если для защиты выбран публичный доступ.

Не включайте логирование request body: в POST /api/analyze передаётся API-ключ.
Логи приложения не содержат тел запросов; политика хранения провайдера LLM и
инфраструктуры хостинга находится вне контроля этого MVP.
