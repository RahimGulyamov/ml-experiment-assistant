# Рабочая среда для ML-разработчика

Run Notes связывает проверяемый срез эксперимента с объяснением модели. Первый
реализованный этап использует выгрузки, не требует встраивать корпоративные токены
в публичный сервис и не меняет обучение или настройки A/B.

## Сейчас: файлы и локальный MCP

Training → скалярный JSON → `/developer` → выбранный workspace → stdio MCP →
разрешённый AI-клиент → объяснение с точными значениями.

Для A/B начало цепочки — агрегированный отчёт по явному шаблону. Это не готовый
адаптер неизвестного внутреннего API. Реальная модель проверена на искусственных
данных; UI конкретного корпоративного launcher пока не проверен.

Файлы можно подготовить в локальной/внутренней копии приложения. Имена исходных
файлов и время точек не нужны для сравнения; выбранные метрики всё ещё могут
содержать внутреннюю информацию. Маршрут передачи и хранение контекста определяет
AI-клиент и политика организации, а не отсутствие собственного облачного хранилища.

## Следующий этап: read-only коннекторы

Перед реализацией адаптера нужен контракт от владельца платформы. Не угадывать
endpoint, параметры, поля или способ авторизации по экрану интерфейса.

| Источник | Контракт | Приёмка адаптера |
| --- | --- | --- |
| Training | Разрешённые run ID, dataset/protocol, список scalar series, точные steps, пагинация, ограничения объёма и статус | Значения на фиксированном шаге совпадают с исходным несглаженным экспортом; статус обучения не выводится из наличия последних точек |
| A/B | Контроль/тест, период и timezone, срез, определения метрик, направление, единицы и метод ДИ, interim/final, коррекция сравнений | Все поля совпадают с фиксированным исходным отчётом; guardrails не теряются; неоднозначные единицы дают ошибку |
| Авторизация | Поддерживаемый машинный/делегированный доступ, scopes и правила аудита | Чтение доступно только разрешённым пользователю проектам; токен не возвращается модели |

Сетевые MCP должны работать внутри разрешённого контура. Необходимы таймауты,
ограничения числа рядов/точек, пагинация и идентификатор снимка. Ошибка доступа
или устаревший срез показываются явно. Инструменты записи, запуска обучения и
раскатки в этот этап не входят.

## Для использования командой

Нужны внутренняя публикация, SSO, проверка прав на каждый источник, аудит без
содержимого токенов и правила хранения выгрузок. Контекст каждой сессии изолирован.
Доступ к общему MCP не должен превращаться в доступ ко всем экспериментам.

До внедрения провести сверку на разрешённых контрольных примерах: одинаковые
метрики/шаги, другой protocol, отсутствующая серия, частичный запуск, пустой ответ,
429/timeout, нулевой baseline, CI через ноль и ухудшение guardrail. Ответ модели
проверяется по значениям инструментов. Учебная публикация не объявляется готовым
корпоративным сервисом до выполнения этих условий.
